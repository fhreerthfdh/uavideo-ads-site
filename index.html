UAVideo Ads
广告管理与报表工具

UAVideo Ads 是一套本地运行的广告管理与报表工具，帮助运营者整理素材、查看广告表现，并对自有或获授权的 Google Ads 账户执行明确指定的操作。

UAVideo Ads is a local Google Ads account management and reporting application. It reads authorized campaign, ad group, creative and aggregate performance data to produce reports, organize game advertising assets, and execute explicitly requested campaign and asset operations. It is intended for the operator’s own or explicitly authorized advertising accounts. This application information and all policy pages are publicly accessible without sign-in.

01 / REPORTING

广告表现与报表

读取广告系列、广告组、素材及汇总表现数据，保存本地快照，用于筛选、比较和运营分析。

02 / CREATIVE WORKFLOW

素材与操作记录

整理图片、视频及广告文案，记录素材信息和操作结果，支持人工检查与追溯。

03 / AUTHORIZED ACTIONS

明确授权的账户操作

在账户权限和操作者明确指令范围内，提交广告素材及创建广告对象。浏览此介绍站点不会执行广告操作。

关于 Google 授权

工具通过 Google OAuth 获取所需的 Google Ads API 访问授权，不要求向开发者提供 Google 密码。本网站是公开的应用介绍和政策页面，不提供账户登录或广告管理后台。

Google OAuth is used to authorize API access. This public website contains product information and policies only; it does not collect Google passwords or operate ad accounts.

为什么需要 Google 数据 / Why we request Google data

本应用使用 Google Ads API 权限 https://www.googleapis.com/auth/adwords，读取获授权的广告账户信息、广告系列、广告组、素材、预算和出价配置，以及展示、点击、费用、转化和转化价值等汇总指标。数据用于生成本地报表、检查广告表现、管理素材和保留操作回执；写入操作只按运营者明确指令执行。OAuth 或运营者配置的服务账号凭据用于获授权的 API 请求。

The Google Ads API scope https://www.googleapis.com/auth/adwords enables authorized reporting and advertising management. Account settings, campaigns, ad groups, creatives, budgets, bids and aggregate performance metrics are used for local reports, performance review, asset management and operation receipts. Account writes require explicit operator instructions. Access uses OAuth or operator-configured service-account credentials.

Google 账户数据不会通过此公开网站发布。查看本页面无需登录；只有实际访问受保护的广告账户时才需要相应授权。Account data is not published on this website. Reading this page requires no login; authorization is required only for actual protected account operations.

内容与使用限制 / Acceptable use

本应用用于合法的游戏广告运营。禁止通过本应用或其 Google API 接入创建、获取、传播或推广 AI 生成的未经当事人同意的私密图像（AI NCII）、性剥削内容，或侵犯隐私及肖像权的内容。运营者须核查素材权利及使用授权，并遵守 Google 政策和适用法律。这是使用限制，不表示应用已实现自动内容识别。

This application is for lawful game advertising operations. It must not be used, including through its Google API integrations, to create, obtain, distribute or promote AI-generated non-consensual intimate imagery (AI NCII), sexual exploitation, or content violating privacy or image rights. Operators must check content rights and consent and comply with Google policies and applicable law. This acceptable-use restriction is not a claim of automated content detection.

使用范围与支持

UAVideo Ads 用于运营者管理的广告账户，暂不提供面向公众的注册服务。Google Ads 是 Google 的产品；UAVideo Ads 是独立工具，并非 Google 官方产品。

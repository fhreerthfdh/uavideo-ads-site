UAVideo Ads

Manage authorized advertising accounts, organize game creatives, and review campaign performance from a local workspace.

UAVideo Ads is an independent application that uses the Google Ads API to retrieve advertising data, produce local reports, and execute explicitly requested campaign and asset operations. It serves the operator's own accounts or accounts the operator has explicit permission to manage.

Why the application requests Google data

The Google Ads API permission https://www.googleapis.com/auth/adwords supports authorized reporting and advertising management. UAVideo Ads uses account identifiers and settings, campaign and ad-group information, creative metadata, budgets, bids, and aggregate impressions, clicks, costs, conversions and conversion values to provide the functions described above.

Access uses Google OAuth or operator-configured service-account credentials. The application does not ask users to give the developer their Google password. Account data and credentials are not published on this website.

How it works

  1. The operator configures credentials and authorizes the relevant advertising account.
  2. The local tool retrieves requested account data and saves reports for review.
  3. The operator reviews assets and explicitly specifies any account operation to execute.
  4. The operator can stop using the tool, revoke account access and remove local records.

This website provides application information and policies. The operational tool runs locally; this website does not provide a public sign-up service, a Google login form, or an online advertising dashboard.

Responsible use and prohibited content

UAVideo Ads is intended for lawful game advertising operations. The application and its Google API integrations must not be used to create, obtain, distribute or promote AI-generated non-consensual intimate imagery (AI NCII), sexual exploitation, or material that violates privacy or image rights.

Operators must check content rights, required consent and advertising-policy compliance. This is an acceptable-use restriction, not a claim that automated content detection has been implemented. Google user data must not be used to train general-purpose AI or machine-learning models.

What UAVideo Ads does in practice

Account and campaign reporting

The operator selects an authorized Google Ads account and a reporting period. UAVideo Ads reads the requested account and advertising resource information and retrieves aggregate performance metrics for that period. The tool saves local JSON or CSV exports and can create a local HTML report. Operators use those reports to inspect campaign performance, compare creative assets and understand recorded advertising costs and conversions. Report interpretation remains the operator's responsibility.

Creative organization and review

The operator supplies images, videos or advertising copy for game promotion. The workflow keeps local asset files, asset identifiers, review notes and operation receipts so the operator can identify the version used for a requested action. Creatives may contain people, devices and game imagery; the operator is responsible for the required rights, consent and compliance review. This public website does not collect visitors' media uploads.

Explicitly requested advertising operations

When the operator explicitly requests an account action, the tool can submit advertising assets and create campaign, ad-group or ad resources using the supplied parameters and the account's permissions. Those requests can contain advertising copy, creative files, targeting settings, budgets and bidding configuration. The resulting resource identifiers or errors are recorded locally for review. Merely visiting this website, reading a report or granting authorization does not itself instruct the tool to create a campaign.

Who can use the operational tool

The operational tool is used in the operator-controlled local environment for owned or explicitly authorized accounts. There is no public sign-up service on this website. The public homepage and policies can be read without signing in. Google authorization is necessary for the local tool to access protected advertising account data; it is not necessary to read this application description.

Where data goes

  1. Authorization: Google issues access under the configured OAuth or service-account authorization. The operator configures credentials locally.
  2. Retrieval: the local tool requests specified advertising account data over HTTPS from Google Ads.
  3. Local processing: responses are organized into operator-controlled reports, asset records and operation receipts.
  4. Requested submissions: selected creative content and advertising parameters are sent to Google only as needed for the requested account operation.
  5. Optional assistance: if the operator explicitly uses an analysis or creative-processing service, only the authorized information necessary for that requested task should be shared, as described in the Privacy Policy.
  6. Stopping access: the operator can stop the tool, revoke Google access and delete local records and controlled backups.

The public GitHub Pages site is separate from this operational data flow. It contains application information, policies and the site-ownership verification file; it does not host advertising account credentials or private reports.

UAVideo Ads

Manage authorized advertising accounts, organize game creatives, and review campaign performance from a local workspace.

UAVideo Ads is an independent application that uses the Google Ads API to retrieve advertising data, produce local reports, and execute explicitly requested campaign and asset operations. It serves the operator's own accounts or accounts the operator has explicit permission to manage.

This is the public application homepage. No login is required to view this page, our Privacy Policy, or our Terms of Service.

Why the application requests Google data

The Google Ads API permission https://www.googleapis.com/auth/adwords supports authorized reporting and advertising management. UAVideo Ads uses account identifiers and settings, campaign and ad-group information, creative metadata, budgets, bids, and aggregate impressions, clicks, costs, conversions and conversion values to provide the functions described above.

Access uses Google OAuth or operator-configured service-account credentials. The application does not ask users to give the developer their Google password. Account data and credentials are not published on this website.

How it works

  1. The operator configures credentials and authorizes the relevant advertising account.
  2. The local tool retrieves requested account data and saves reports for review.
  3. The operator reviews assets and explicitly specifies any account operation to execute.
  4. The operator can stop using the tool, revoke account access and remove local records.

This website provides application information and policies. The operational tool runs locally; this website does not provide a public sign-up service, a Google login form, or an online advertising dashboard.

Responsible use and prohibited content

UAVideo Ads is intended for lawful game advertising operations. The application and its Google API integrations must not be used to create, obtain, distribute or promote AI-generated non-consensual intimate imagery (AI NCII), sexual exploitation, or material that violates privacy or image rights.

Operators must check content rights, required consent and advertising-policy compliance. This is an acceptable-use restriction, not a claim that automated content detection has been implemented. Google user data must not be used to train general-purpose AI or machine-learning models.
